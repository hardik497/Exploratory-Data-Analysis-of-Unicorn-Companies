# Exploratory Data Analysis of Unicorn Companies

## Overview

This project analyzes the Unicorn Companies dataset to explore funding trends, industry distribution, geographical patterns, and investor relationships. The analysis includes data preprocessing, visualization, statistical analysis, and K-Means clustering to uncover meaningful business insights.

## Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- GeoPandas
- NetworkX
- Scikit-learn
- Statsmodels

## Project Highlights

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Funding and valuation analysis
- Country and industry analysis
- Correlation and regression analysis
- K-Means clustering using the Elbow Method

## Key Findings

- Most unicorn companies are concentrated in North America, Europe, and Asia.
- Technology-related industries dominate the unicorn ecosystem.
- Funding distribution is highly right-skewed, with a few companies raising exceptionally large investments.
- Investor count has a positive but weak relationship with total funding raised.
- K-Means clustering identifies meaningful groups of companies with similar characteristics.
